# 小米 10（umi）iOS 16 研究

**维护者：[leafall903](https://github.com/leafall903)** · [English / 默认首页](README.md) · 更新于 2026-10-26

当前发布的是 **iOS 16.5 / 20F66 的 v6 源码检查点**：上一轮已经上机、机主反馈“已经没有显示错误”的版本。可以进入 iPhone 锁屏与桌面；16.5 壁纸已出现，v5 小组件反馈正常，v6 保留相关修复。尚未测试的 v7 不在此次发布中。

[v6 发布页](https://github.com/leafall903/ios-sweet-umi/releases/tag/umi-ios16.5-v6) · [详细英文功能表](README.md) · [设备源码](devices/umi/README.md) · [构建与复现边界](docs/reproduction.md)

## 已做到和仍有问题

| 项目 | 当前结果 |
| --- | --- |
| 启动与存储 | UFS / SMMU 接管，HFSX 根卷启动至 SpringBoard |
| CPU | 4 A55 + 4 A77 八核初始化及 SGI1 测试通过 |
| 输入 | 本机 ST FTM5 触控、电源与音量键近期可操作；其他触控批次未验证 |
| 图形 | A650 最小渲染与 GL 链路已跑通；仍有 CPU 最终帧缓冲复制，不能等同于完整 Metal 或所有应用都已 GPU 加速 |
| 壁纸与小组件 | 16.5 壁纸出现，v5 机主确认小组件正常；v6 测试未再报告此前显示破碎。尚未逐项审计所有样式和组件 |
| 流畅度 | 有改善，但仍需优化；没有 v6 持续稳定 60 fps 的测量证据 |
| 应用 | 地图、设置里的日期与时间有已知故障；键盘完整功能未重新确认 |
| 其他硬件 | Wi-Fi、蜂窝、蓝牙、音频、相机、充电与真实电量等未验证可用 |
| Apple 服务 / 安全硬件 | 不提供激活材料，也不声称 Apple ID、App Store、Face ID 或 SEP 数据保护已可用 |

本机为 8 GB / 256 GB、小米 10 `umi`，骁龙 865 / Adreno 650。用户空间为 iPhone X 的 16.5 / 20F66，移植内核实际基线为 **XNU 8796.141.3**，两者版本须分别说明。

**这台手机的 Android userdata 已被实验根卷替换，不能称为无损双系统。** Fastboot 临时加载启动镜像，不表示系统盘未写入闪存。

## 此次公开内容
