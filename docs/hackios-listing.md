The public [HakiOS website repository](https://github.com/oosexgang/hackios-web) uses maintained site content rather than a verified automatic device-registration form. Its published contact route should be checked when preparing a submission. Website inclusion and code merging are separate decisions; publishing this repository does not itself secure either.

## Evidence now available

- A pinned, tagged **iOS 16.5 v6 source checkpoint** with kernel and user-space changes, dependency provenance and license notices.
- A Mi 10 device page with owner-observed results: iPhone UI reached, eight-core bring-up, touch/keys, wallpaper/widgets and the experimental A650 GL path.
- Explicit known failures and validation limits, including incomplete Maps/Date & Time support, ongoing performance work and no sustained 60 fps claim.
- Public host regressions and kernel-patch application checks, with a clear distinction from on-device UI evidence.

A sanitized continuous demonstration and independent clean build remain useful additions before asking for an officially maintained support claim. Community source-only rules exclude iOS screenshots and firmware/system files from this repository; do not attach private device data or such assets to a listing patch.
